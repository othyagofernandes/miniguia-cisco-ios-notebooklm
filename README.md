# Miniguia de Estudos - Cisco IOS utilizando NotebookLM
Miniguia de estudos sobre Cisco IOS utilizando NotebookLM e Engenharia de Prompts.

## Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO sobre Inteligência Artificial aplicada aos estudos.

O objetivo foi utilizar o NotebookLM como ferramenta de aprendizagem ativa para organizar conteúdos, produzir resumos, validar conceitos técnicos e criar um guia de estudos sobre o sistema operacional Cisco IOS.

---

# Objetivos

- Entender o funcionamento do Cisco IOS.
- Conhecer sua arquitetura.
- Aprender os principais modos de operação.
- Identificar as diferentes versões do IOS.
- Compreender os comandos básicos de configuração.
- Criar um material reutilizável para futuras revisões.

---
