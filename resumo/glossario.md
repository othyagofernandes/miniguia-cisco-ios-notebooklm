## Glossário

# CLI

Interface de Linha de Comando.

# IOS

Sistema Operacional Cisco.

# Startup-config

Configuração salva na memória NVRAM.

# Running-config

Configuração atualmente em execução.

# NVRAM

Memória não volátil.

# Flash

Local onde fica armazenado o IOS.

# RAM

Memória temporária utilizada pelo equipamento.

# Hostname

Nome do equipamento.

# VLAN

Rede Local Virtual.

# Interface

Porta física ou lógica do equipamento.
