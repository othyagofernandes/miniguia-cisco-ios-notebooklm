# Resumo Geral

## O que é o Cisco IOS

Cisco IOS (Internetwork Operating System) é o sistema operacional utilizado em roteadores e switches Cisco responsável por controlar o hardware e permitir a configuração da rede.

---

## Principais características

- Interface CLI
- Gerenciamento remoto
- Segurança
- Roteamento
- Switching
- VLANs
- Protocolos de rede

---

## Modos de operação

- User EXEC
- Privileged EXEC
- Global Configuration
- Interface Configuration
- Line Configuration

---

## Principais comandos

enable

configure terminal

## Boas práticas

Salvar sempre a configuração.

Documentar alterações.

Realizar backups.

Utilizar senhas fortes.

Atualizar versões do IOS quando recomendado.
